# School of Toppers — Website

A bold, editorial one-page website concept for **School of Toppers**, a Bhopal coaching institute for grades 8–12, boards, JEE, NEET, and NDA preparation.

## What is included

- Hero section with brand positioning, classroom illustration, trust markers, and primary CTAs.
- Results gallery with student achievements and proof-led storytelling.
- Faculty cards with credentials and teaching philosophies.
- Transparent fee table with enroll buttons.
- Contact/admissions section with call, WhatsApp, and enquiry form flows.
- Responsive CSS, reduced-motion support, and accessible form semantics.

## Run locally

```bash
python3 -m http.server 8080
```

Then open `http://127.0.0.1:8080`.
